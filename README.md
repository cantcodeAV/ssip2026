# Green Leaders Foundation 🌿

A modern, production-ready, responsive single-page website for **Green Leaders Foundation**, an 80G tax-exempt non-profit organization dedicated to quality education for underprivileged children, hunger relief food drives, and environmental clean-up initiatives across India.

## 🌟 Core Pillars

1. **Quality Education for Underprivileged Children**: Providing annual learning kits, after-school academic mentorship, STEM labs, and digital tablets to first-generation learners.
2. **Hunger Relief & Food Security**: Operating daily community slum kitchens serving hot, protein-rich meals, and running a nocturnal surplus food rescue fleet.
3. **Clean-Up & Ecological Restoration**: Leading citizen coastal beach cleanups, plastic interception, waste segregation, and planting native Miyawaki micro-forests.

---

## 🚀 Key Features

- **Sticky Modern Navigation**: Responsive navbar with quick links, mobile hamburger drawer, and high-contrast "Donate Now" CTA.
- **Hero Showcase**: Live dynamic impact counter (`52,400+ Lives Touched Across 14 Cities`), floating glassmorphism stat badges, and dual primary CTAs.
- **Filterable Initiatives Grid**: Interactive category tabs (`[All Drives, Education, Food Drives, Clean-Up]`) with progress bars and detail modals.
- **Interactive Impact Calculator**: Live numerical counters on scroll and interactive slider/preset selector recalculating meals served, student kits funded, trees planted, and direct Section 80G tax deductions.
- **Upcoming Volunteer Drives**: Timeline card layout for upcoming ground drives with instant volunteer role registration.
- **Financial Transparency & Trust**: Visual breakdown of fund allocation (84% Direct Programs, 10% Logistics, 6% Ops & Admin) alongside statutory badges (80G, 12A, CSR-1, NITI Aayog Darpan).
- **Interactive Donation & Receipt Modal**: 
  - Frequency toggle (`[One-Time | Monthly Impact Guardian]`).
  - Preset chips & custom amount inputs.
  - Realistic mock payment selectors for **UPI / QR Code**, **Credit/Debit Card**, and **Net Banking**.
  - Instant generated **Digital 80G Tax Exemption Receipt** with printable PDF styling.

## 🛠️ Technology Stack

- **Markup**: Pure HTML5 (Semantic & Accessible)
- **Styling**: Tailwind CSS via CDN (`https://cdn.tailwindcss.com`) + Custom CSS (`styles.css`)
- **Typography**: Google Fonts (*Plus Jakarta Sans*)
- **Icons**: FontAwesome 6 Icons
- **Scripting**: Vanilla JavaScript (ES6+ modular state management in `app.js`)

## 💻 Getting Started Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/cantcodeAV/ssip2026.git
   cd ssip2026
   ```

2. Open `index.html` directly in any web browser, or launch a lightweight local server:
   ```bash
   # Using Python 3
   python -m http.server 8080

   # Or using Node.js npx serve
   npx serve .
   ```

3. Visit `http://localhost:8080` in your browser.
